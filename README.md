# Agent Rules

这个仓库保存个人使用的 AI 助手工作规则，包括协作方式、共享存储与长任务安全、代码和 Git 约定，以及飞书 CLI 的使用原则。

规则正文见 [AGENTS.md](AGENTS.md)。这是个人工作习惯，可以根据自己的需求调整。

## 在新电脑上使用

1. 克隆或下载本仓库。
2. 查看并按需调整 [AGENTS.md](AGENTS.md)。
3. 将规则放到所使用工具读取用户级指令的位置。对于 Codex，通常是其配置目录下的 AGENTS.md；如果通过 Cindy 使用 Codex，请确认 Cindy 使用的 Codex 配置目录。
4. 更新仓库后，需将更新同步到各电脑实际使用的规则文件；仅拉取仓库不会自动更新其他位置的文件。

不同工具或执行引擎对规则文件的支持和读取位置可能不同，请以各自的说明和实际配置为准。飞书相关规则依赖本机安装并配置 lark-cli。
